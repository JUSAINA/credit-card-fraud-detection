# Credit Card Fraud Detection & BI Dashboard

## Project Overview
Built an end-to-end fraud detection system using XGBoost and Power BI.

## Technologies
- Python
- Pandas
- Scikit-Learn
- XGBoost
- Power BI
- DAX

## Results
- Accuracy: 99.96%
- Precision: 94.05%
- Recall: 80.61%
- F1 Score: 86.81%
- ROC-AUC: 90.30%
