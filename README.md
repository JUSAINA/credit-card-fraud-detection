# Credit Card Fraud Detection & Business Intelligence Dashboard

## Project Overview

This project presents an end-to-end Credit Card Fraud Detection system built using Machine Learning and Business Intelligence tools. The solution identifies fraudulent transactions using an XGBoost classifier and provides interactive analytics through a Power BI dashboard.

The project demonstrates the complete data analytics lifecycle, including data preprocessing, exploratory data analysis, machine learning model development, model evaluation, and business intelligence reporting.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* XGBoost

* DAX

## Dataset

* European Credit Card Transactions Dataset
* Highly imbalanced fraud detection dataset
* Over 284,000 transaction records
